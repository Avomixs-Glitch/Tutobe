# Code de conduite

Nous souhaitons un espace accueillant, curieux et respectueux. Toute interaction dans les issues et discussions doit rester constructive, inclusive et centrée sur le produit.

Les comportements abusifs, discriminatoires, intimidants ou le partage de données personnelles sans consentement ne sont pas tolérés. Pour signaler un problème, utilisez le canal de modération configuré par les responsables du dépôt.
