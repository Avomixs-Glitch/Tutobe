# Politique de sécurité

Si vous pensez avoir identifié une vulnérabilité dans Tutobe ou son extension Chrome, ne publiez pas de détails exploitables dans une issue publique. Utilisez le canal de signalement privé configuré dans l'onglet **Security** du dépôt.

Incluez :

- une description du problème ;
- les étapes reproductibles ;
- l'impact potentiel ;
- toute suggestion de correction, si vous en avez une.

Merci de nous laisser un délai raisonnable pour corriger le problème avant toute divulgation publique.
