# Contribuer à Tutobe

Merci de vous intéresser à Tutobe. Ce dépôt est une vitrine publique : le code de l'application n'y est pas distribué.

Vous pouvez néanmoins contribuer de trois façons utiles :

1. Ouvrir une issue pour signaler une information inexacte, une suggestion produit ou un problème de documentation.
2. Démarrer une discussion pour partager un cas d'usage ou une idée.
3. Partager un retour détaillé dans une discussion GitHub.

Avant de publier, veillez à ne jamais inclure d'informations personnelles, de clés API, de captures contenant des données privées ou de contenu protégé sans autorisation.

## Contributions de code

Le code source et l'infrastructure de Tutobe sont propriétaires et privés. Les pull requests de code ne peuvent donc pas être acceptées dans ce dépôt.
